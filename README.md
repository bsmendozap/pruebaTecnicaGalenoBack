# pruebaTecnicaGaleno

AL INICIAR EL PROGRAMA ESPERAR A QUE SE ACTIVE LA BASE DE DATOS, POR SER SERVICIO GRATUITO SE PONE EN PAUSA AUTOMATICAMENTE PARA NO GASTAR RECURSOS

**RUTAS**

LOGIN: http://localhost:3000/api/auth/login
REGISTER: http://localhost:3000/api/users/register
UPDATE USER:  http://localhost:3000/api/users/update/id
DELETE USER: http://localhost:3000/api/users/delete/id

**PRODUCTOS**
AGREGAR PRODUCTO: http://localhost:3000/api/products
EDITAR PRODUCTO: http://localhost:3000/api/products/id
ELIMINAR PRODUCTO: http://localhost:3000/api/products/id
VER PRODUCTO: http://localhost:3000/api/products
BUSCAR POR ID: http://localhost:3000/api/products/id

**API EXTERNA**
LOGIN: http://localhost:3000/api/external/login
GET PRODUCTOS: http://localhost:3000/api/external/products
